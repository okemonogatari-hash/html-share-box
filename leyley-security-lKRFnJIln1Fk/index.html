「お願い文をコピー」を押して、ChatGPTの新しいチャットに貼り付けて送るだけです。会のことは、もう中に書いてあります。

・日時：2026年11月5日（木）15:00〜17:00
・サポート：おけもんさん（1Passwordとセキュリティ設定のオフ会を開いている方）

【まだ決まっていないこと】
・開催場所（公式オフィスか、それ以外か）
・募集する人数の正確な数、募集の締切、参加を承認制にするか
・タイトルと概要文

【進め方】
1. まだ決まっていないことを、1回に1つずつ質問してください。選択肢があるときは2〜3個の案を出して、私が選べるようにしてください。
2. 全部そろったら、リベシティのオフ会チャット作成画面の項目の順に、入力する内容を一覧で出してください。項目は「タイトル／開催の種類（公式オフィスで開催するか）／オフィスを予約済みか／会場／開催日・開始時刻・終了時刻／オフ会カレンダーへの登録／募集状況／定員／プロジェクターの有無／参加の承認制／フォロワーへの通知／概要」です。私の画面の項目と違っていたら、画面に合わせて言い直してください。
3. 概要文は、初心者が「これなら参加できそう」と思える、やさしい文にしてください。こんな方におすすめ・当日の流れ・持ち物・注意を入れてください。
4. 最後に、チャットを作ったあと参加者へ送る「当日までの準備」の案内文も作ってください。

【守ってほしいこと】
・パスワードや確認コードは、私にもチャット欄にも書かせないでください。会の中でも、画面のパスワードは人に見せない前提で書いてください。
・公式オフィスで開く場合、オフィスの利用予約は参加者それぞれが行うことを概要に入れてください。私がまだ予約していなければ、「予約済み」にはチェックしないよう教えてください。
・最後の「作成する」ボタンは私が押します。押す前に、日時・場所・定員・通知先をもう一度確認させてください。

ChatGPT以外のAI（Gemini・Claudeなど）にも同じ文で使えます。AIによって答え方は少しずつ違うので、気になる所は「もっと短く」「やさしく」と頼み直してください。

⑤ 作成ボタンを押す前に

  1. 場所を決める。 公式オフィスなら、まずご自身の利用予約を取ります。取れていなければ「予約済み」にはチェックしません。
  2. チャッピーの一覧を見ながら画面を埋める。 タイトル、開催の種類、日時、定員、概要、通知の範囲を入れます。
  3. 自分の目で確認する。 日付が11/5、時間が15:00〜17:00、定員と通知先が思った通りか。よければ「作成する」を押します。
  4. 作れたら、おけもんに一言。 チャットに入って、当日の準備の案内を一緒に整えます。

画面の項目は変わることがあります。いまのリベシティの画面を優先してください。分からないところは、DMでいつでも聞いてくださいね。
