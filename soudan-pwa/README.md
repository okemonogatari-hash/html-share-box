中身は `diagrams/shindan-menu-guide.html` と同じもの。触っているのは「届け方」だけ。

公開URL：https://okemon-soudanjo.pages.dev

## 本番でだけ出た穴が2つあった（localhostでは絶対に見つからない）

**① `/index.html` は Cloudflare Pages で `/` へ 308リダイレクトされる**

Service Worker の取得先を `./index.html` にしていたため、
「リダイレクトされたものは信用しない」という自前の検査に**自分で引っかかり**、
インストールが毎回中止されていた。キャッシュの箱だけできて中身が空になる。
→ 取得先を `./` に変えて解決。

**② manifest の `start_url` も `./index.html` だった**

同じ308を踏む。ホーム画面から起動した時の入口がずれる。
→ `./` に統一。SWの取得先と揃えた。

どちらも **localhost（python http.server）では `/index.html` がそのまま200で返るので再現しない**。
ローカルで全部通してから本番で2回転んだ、というのが今回の実話。

## オフラインの仕組み（`sw.js` が何をしているか）

1. **開く時は必ず手元のコピーから出す。** ネットを一切待たない。
   圏外でも機内モードでも、タップした瞬間に開く。
2. **新しい版は、開いた後に裏で取ってくる。** 反映は次に開いた時。
   「起動が遅い」と「古いまま」を両方避けられる。
3. **取ってきたものが本物か調べてから差し替える。**
   `index.html` に `OKEMON-SOUDAN-OK` という合言葉を1行仕込んである。
   これが無いものは、通信が成功していても手元のコピーを上書きしない。

**3番目が肝。** ここが無いPWAは、ログイン画面やWi-Fiの認証画面を「新しい中身」だと思って
焼き付けてしまい、二度と開かない箱になる。今回の相談で一番怖かったのがこれ。
実際にサーバー側を認証画面に差し替えて試したが、手元のコピーは無傷だった。

## iPadに入れる（受け取る側の手順）

1. Safariで公開URLを開く
2. 下の **共有ボタン** → **「ホーム画面に追加」**
3. 出てきたアイコンから起動する

初回だけネットが要る。2回目からは電波が無くても開く。
初回に開いた時、画面の下に「ネットが無くても開けるようになりました」と数秒出る。

## 公開する（おけちゃんが押すところ）

> 初回の公開は 2026-08-24 に **やり方B（コマンド）** で完了済み。
> 以降の更新もコマンドでできる（認証は端末に保存されている）。

### やり方A：Cloudflareの画面にドラッグ&ドロップ（3分）

1. https://dash.cloudflare.com を開く
2. 左メニュー **Workers & Pages** → **Create** → **Pages** → **Upload assets**
3. プロジェクト名を入れる（例：`okemon-soudanjo`）
4. **このフォルダごと** 枠の中にドラッグ&ドロップ
5. **Deploy site** を押す → `https://okemon-soudanjo.pages.dev` が出る

### やり方B：コマンドで上げる

```
npx wrangler pages deploy . --project-name okemon-soudanjo --branch main --commit-dirty=true
```

初回だけ `npx wrangler login` が要る（ブラウザでAllowを押すだけ・2026-08-24に実施済み）。
プロジェクトを新しく作る時は先に
`npx wrangler pages project create <名前> --production-branch main` を打つ。
これを飛ばすと、デプロイの途中で本番ブランチを対話で聞かれて止まる。

### 更新する時

`index.html` を差し替えて、同じ手順でもう一度上げる。
端末側は次に開いた時に自動で新しくなる（上の仕組み2）。
**`manifest.webmanifest` やアイコンを変えた時は、`sw.js` の `VERSION` を必ず1つ上げる。**
ページ本体は裏で自動更新されるが、アイコンとmanifestは一度保存されると更新されない。
VERSIONを上げると新しい箱が作られ、古い箱は自動で消える（実測済み）。
