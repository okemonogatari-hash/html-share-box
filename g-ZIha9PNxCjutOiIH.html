この減衰は、実は2つの別々の現象が重なって起きています。分けて見る必要があります。

現象①　初週組の寿命切れ

8月前半に公開した動画（K0〜K6）が、ショート特有の「公開24〜72時間でピーク→その後は下がる」寿命カーブどおりに落ちてきています。これ自体は動画の寿命であり、想定内の動きです。

現象②　新作が広がらない

初週組の後を継ぐはずの新作（K13以降）が、寿命カーブに乗る前の「ごく小さいテスト配信」で止まっています。ここが今回のいちばんの論点です。

5もう疑わなくていいこと

これまでの調査で、原因になり得た候補を実測ベースで一つずつ確認してきました。以下はすべて「原因ではない」と確認済みです。

  • ✓ 著作権クレーム 動画ごとのクレーム画面を目視確認。申し立てゼロ。
  • ✓ アップロード時の設定不備 公開範囲・審査状況・年齢制限などをAPIで全数確認。異常なし。
  • ✓ 投稿の頻度が足りない うちは1日1.3本ペース。伸びている競合チャンネルも1.1本／日とほぼ同水準。
  • ✓ 投稿の間隔が短すぎる 公式ヘルプ・先人の実測データと照らし合わせて根拠が弱いことを確認。
  • ✓ チャンネルが新設だから 同時期に立ち上がった競合2チャンネルは、即座に新作が配信されています。
  • ✓ チャンネルごと締め出されている SHORTSのフィード比率は全期間94〜99%を維持。経路自体は生きています。
  • ✓ テーマ・尺・訴求の「選び方」 当たっているテーマ・尺は競合と一致していることを個別に確認済みです。※「最初の数十人に見せた時の反応」だけは可能性Aとしてまだ残しています（次の章）。

6残る2つの可能性と、決着のつけ方

疑わしいものを削っていった結果、残っているのはこの2つです。

可能性 A

最初の小さなテスト配信での反応（スワイプ率・視聴維持率など）が、そこから先に広げてもらえる基準に届いていない。

可能性 B

このチャンネルに割り当てられる新規配信の枠そのものが、8月16日以降絞られている。

この2つを見分けるには、テスト配信の段階でどれだけ表示されたか（インプレッション数）が必要です。これまで使っていたデータには含まれておらず、8月24日にレポート機能を新しく有効化しました。初回のデータは8月25日以降に届き始めます。届き次第、AかBかを数字で判定します。

7次の一手（9/1のMTGまで）

BGMを新しい音源に差し替え済みのストック4本（K18〜K21）を、8月25日から1日1本ずつ出していきます。

K18〜K21を出し切ると、公開本数は21本になります。もともと「20〜30本たまったら一度分析する」という約束と合流するタイミングです。ここまでの実測結果とインプレッション実数をあわせて、9月1日のMTGで今後の戦略を決めましょう。

当日は「何を作るか」の前に、「なぜ新作が広がらないか」を数字で確定させるところから話せる状態にしておきます。
