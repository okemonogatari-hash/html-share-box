HOW TO MAKE

サンプルムービーの作り方

3本のサンプルは、動画編集ソフトを使わずに作りました。Claude Code に頼み文を貼って、できた試しを見て、一言返す。その繰り返しです。同じやり方でまねできるように、わたしが実際に使った頼み文を置いておきます。

しくみ

Claude Code が、絵と動きをプログラムで書きます。それをブラウザで1コマずつ撮って、曲と合わせて mp4 にします。人が動かすのは、頼み文を貼る所と、試しを見て感想を返す所だけです。

STEP 1頼み文を貼るゴールと材料を渡す
STEP 2試しを見る最初の10秒
STEP 3一言返す直しは1回に1か所
サンプル1箱庭。下の「1分ムービーの頼み文」で作りました。
サンプル2方眼。同じく「1分ムービーの頼み文」で作りました。
サンプル3飛び出す絵本。公開している「飛び出す絵本ムービー キット」で作りました。

用意する物

  • Claude Code（有料プラン。わたしは Max で作りました）
  • 自分で書いた文章（ホームページ、プロフィール、一問一答など）
  • 写真とロゴ（ホームページに出している物）

わたしは Mac で作りました。動画を作るための道具（Node.js、ffmpeg など）が足りない時は、Claude Code が入れ方を案内してくれます。

1分ムービーの頼み文

新しいフォルダを1つ作り、写真とロゴを入れてから、そのフォルダで Claude Code を開きます。［ ］の所を書き換えて、下の文を貼ります。

1分ムービーの頼み文
1分のモーショングラフィック（音つき・1920×1080のmp4）を作ってください。

■ 見る人と、起こしたい気持ち
［土地の境界が少し気になっている家の持ち主］が、スマホで見せてもらって、「［この人に頼みたい］」と声に出す動画です。約60秒。名刺代わりに人へ見せます。

■ 材料
・わたしが自分で書いた文章：［ホームページのURL。またはプロフィールの文章をここに貼る］
・写真とロゴ：このフォルダの中の画像
画面に出す名前・数字・地名・経歴は、この材料に書いてある事だけにしてください。足したくなった事は、足さずにわたしへ聞いてください。

■ 曲
曲と効果音は、あなたがプログラムで作ってください。

■ 終わりの条件
・mp4 が1本できていて、音が入っている
・書き出した動画から2秒おきにコマを切り出して、あなたの目で全部見る。字の欠け・はみ出し・重なりが無い
・スマホで送れる軽い版（1280×720）も作る
・できた動画の場所を教える

舞台・色・動き・構成は、全部あなたが決めてください。まず最初の10秒の試しを見せてください。
あなたが今できる最高のモーショングラフィックで、見た人が思わず「［この人に頼みたい］」と声に出す1本を作ってください。出し惜しみせず全力で。

サンプル1とサンプル2は、この形の頼み文を2つの別のチャットに渡して作りました。同じ文でも、箱庭と方眼という別の世界が返ってきます。2本作って見比べると、選ぶ楽しみが増えます。

サンプル1とサンプル2の曲は、わたしが Suno で作った曲です。サンプル3の曲は、Claude Code がプログラムで作りました。

飛び出す絵本の頼み文

絵本は、作り方をまとめたキットを公開しています。いつもの Claude Code に、次の1文を貼ります。

絵本の最初の1文
飛び出す絵本のムービーを作りたいです。このページを読んで、一緒に作ってください。 https://okemonogatari-hash.github.io/html-share-box/ehon-kit/start.md

サンプル3では、続けて次の文を足しました。

サンプル3で足した文
人の紹介の絵本です。材料は、わたしが一問一答に自分で書いた話です：［一問一答の文章を貼る］
この話を、昔話の語り手が真顔で読む絵本にしてください。冗談は足さず、書いてある話だけで笑える形にしてください。本人や仕事を下げる笑いにはしないでください。
写真はこのフォルダの中の画像を、白ふちのシールにして使ってください。
最後は「［境界のことなら、あおいろへ。］」で締めてください。

キットのページには、お手本の動画と、困った時の言い方も載せています。

飛び出す絵本ムービー キットを開く

うまくいく3つのコツ

  1. 「だれが見て、何と声に出すか」を1行で決める。「かっこいい動画」と頼むより、「境界が気になっている持ち主が『この人に頼みたい』と声に出す」と頼む方が、中身が決まります。
  2. 自分で書いた文章をまるごと渡す。画面の言葉は、ホームページや一問一答の文章からそのまま取りました。AIに要約させた言葉より、自分で書いた言葉の方が伝わります。
  3. 作り方は指示しない。色や動きや構成は任せます。伝えるのは、ゴールと材料と終わりの条件だけです。

試しを見たあとの返し方

直してほしい所は、1回に1か所。「何秒の、何が、どうなってほしいか」を書きます。直し方は書きません。サンプル1で実際に送った文です。

直しを頼む文（実例）
約12〜15秒の「その不安、いっしょに晴らしませんか。」の3行目が、屋根と札に重なって読めません。
この字が出ている間じゅう、家・屋根・札のどれとも重ならずに、最後の「。」まで読める状態にしてください。ほかは今のままで。

別のチャットに見てもらう

作ったチャットは、自分の作品をほめがちです。新しいチャットを開いて、動画だけを見せると、初めて見る人の感想が返ってきます。サンプル1は、この感想で冒頭の色と動きを直しました。

初めて見る人の目で見てもらう文
この動画を、初めて見る人の目で見てください：［mp4 の場所］
1秒おきにコマを切り出して、全部を順に見てから答えてください。
見る相手は［家の境界が少し気になっている持ち主］です。
1. 「この人に頼みたい」と声が出ますか。出るなら何秒の、どの絵とどの言葉ですか。出ないなら、どこで気持ちが離れましたか。
2. 見終わって、この人がどんな人で、何を頼めるかを1〜2行で言えますか。
3. 字の欠け・はみ出し・重なり、読む前に消える字、止まって見える所はありますか（秒で）。
4. 直すなら1か所だけ、どこですか。

かかった時間

1本あたり30分から1時間ほどです。その間、Claude Code が自分で作り、自分でコマを見て直します。サンプル1は、そのあと直しを2回頼みました。

困った時

途中で止まった：「続けてください」と送ります。
エラーが出た：出た文をそのまま貼って、「どうすればいいですか」と聞きます。
「このコマンドを動かしていい？」と聞かれた：読んで、大丈夫そうなら許可します。
音が気になる：AIは音を聞けません。自分の耳で聞いて、「何秒の音が大きい」と伝えます。
語りを入れたい：サンプル3の語りは、Gemini の読み上げ（有料）を使いました。パソコンに入っている読み上げ声でも、まず形にできます。
