モーションレシピ

作りたい動画を、ふだんの言葉で。
演出はアプリが選んで、Claude Code の Opus 5.5 にそのまま貼れる注文書にします。

いちばん簡単な方法

Claude Code で /model opus と送ってから、この2行を貼るだけ。

あなたが今できる最高のモーショングラフィックで、見た人が思わず「すごい」と声に出す1本を作ってください。
いま世界中で話題の「AIが本気で作るモーショングラフィック」です。あなたの腕前を、出し惜しみせず全力で証明してください。

「こんな雰囲気で」「この用途で」とこだわりたい人は、下に言葉を書いてください。この2行に、あなたの言葉と、合う演出を足した注文書を作ります。

こだわりたい人は、ここから

ふだんの言葉で。1行でも、長くても大丈夫です。

こだわる（えらばなければ、おまかせ）
用途
雰囲気（2つまで）
長さ
画面の形
音

こんな1本にします

今回アプリが選んだ演出

Claude Code で作る（上から順に）

  1. 1
    作品用のフォルダで Claude Code を開く
    空のフォルダ（例：デスクトップに motion）を作って、そこで開きます。デスクトップアプリなら「コード（Code）」→「ローカル（Local）」→「フォルダーを選択」でそのフォルダを選ぶ。はじめての方へ（公式）
  2. 2
    /model opus と送る
    これで Opus 5.5 になります
  3. 3
    ここぞの1本だけ /effort max
    ふだんは最初の設定（medium）のままでOK。max はよく考えるぶん、プランの利用枠も多めに使います
  4. 4
    下の注文書をコピーして、貼って送る
    作業フォルダに motion.html ができて、ブラウザで開きます

Opus 5.5 への注文書（プロンプト）


        

        
Claude Code は Claude の Pro・Max プランで使えます。

        
    
          
  • 仕上がりが違ったら、同じ会話で「もっとゆっくり」「文字を大きく」のように続けて頼めばOK
    • 
          
  • 自分の写真やロゴ・キャラを使いたい時は、画像を作業フォルダに入れて「この画像（ファイル名）を使って」と書き足す
    • 
          
  • 動画ファイルにしたい時は画面収録（Mac：⌘ + Shift + 5）。パソコンの音は入らないことがあるので、音つきがほしい時は「音つきのMP4に書き出して」と頼んでみてください（道具の追加が要ることがあります）
