# ひらく、紙の森

開くと、小さな森の暮らしが立ち上がる。紙の厚みと折り目を、角度を変えて眺めるブラウザ作品です。

- 公開先: https://okemonogatari-hash.github.io/html-share-box/astra-paper-forest-2026-10-03/
- 入口: `index.html`
- 再利用できる依頼文: `making.html`
- 制作記録: `PROCESS.md`

## 起動

作品フォルダで次のコマンドを実行し、ブラウザで `http://localhost:8765/` を開きます。JavaScriptモジュールを使うので、HTMLの直接ダブルクリックではなくHTTPで配信してください。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

パッケージの導入やビルドは不要です。画面表示後に通信を必要とする機能はなく、外部の画像、フォント、ライブラリ、有料APIは読み込みません。作品棚と参考資料のリンクは、クリックした時にそのページを開きます。

## 操作

| 操作 | 実装 |
|---|---|
| 開き具合 0〜100% | `#opening` |
| ひらく／とじる | `#toggle-book` |
| ドラッグで回す | `#scene` |
| 矢印キーで回す、+/−で拡大縮小、Homeで視点を戻す | `#scene`をフォーカス |
| 正面／上から／近くで | `[data-view="front"]` / `overhead` / `detail` |
| 昼／夕暮れ | `#daylight` / `#evening` |
| 折り目 | `#fold-guides` |
| 全操作を初期化 | `#reset` |
| PNG保存 | `#save-png`。作成後は`#download-link`から再取得可 |
| 作り方の依頼文をコピー | `making.html` の `#copy-prompt` |

端末の「動きを減らす」設定では、開閉と視点の補間をせず最終状態に直接移ります。操作・開閉補間・リサイズ・初回フォント準備時だけ描画し、静止中のループはありません。標準倍率では全方向の実頂点を余白内に収め、「近くで」とキーボードによる明示拡大では大きさを優先します。

## 実装

- `model.mjs`: 開き具合、紙の折り畳み、左右ページの回転、投影と動的な画面内調整。
- `renderer.mjs`: 本、川、橋、木、家、窓、喫茶の看板、花、狐、灯りなどの独自形状。
- `gpu.mjs`: 外部依存のないWebGL描画。凹多角形の三角形分割、深度テスト、紙の繊維、紙面の照明、半透明の接地影、文字テクスチャ。
- `app.mjs`: 入力、有限の補間、再描画制御、Canvasの瞬間をコピーしてPNG化。
- `style.css`: 画面の色、組版、操作パネル、375px表示。

折り畳みは見た目を楽しむための幾何表現です。実際の紙の応力や糊の伸びを解くものではなく、このまま印刷・切断するための型紙でもありません。接地影は重ねた半透明形状であり、正確な影の物理計算ではありません。WebGLが使えない場合は、親担当の実出力`poster.png`と別ブラウザの案内を表示します。

## 検査

```sh
node --test qa/model.test.mjs
node --check app.mjs
node --check gpu.mjs
node --check renderer.mjs
node --check model.mjs
```

数理検査は、入力境界、閉時のページ間への収納、有限な頂点、PCと375px相当での全方向の画面内調整、凹多角形の面積保持を確認します。ブラウザの見た目、WebGL、画像保存、タッチの成功はこの検査単独では証明しません。

親担当の実ブラウザ受入は、この作品の外の `../runs/2026-10-03-1912/` にあります。`revised-browser-qa.json`、`revised-interaction-qa.json`と各画像が、初回不具合修正後の実操作の証拠です。最終の全方向調整は `final-browser-qa.json`、`edge-qa.json`、`review.md` で確認済み。公開状態は `public-readback.json` に保存します。

## 受入の要点

1. 100 / 60 / 25 / 0%を、正面・横・裏から見る。表紙やページを裏側の物が透けない。
2. 375px表示で操作が見え、横にあふれない。
3. 正面・上から・近く、ドラッグ、矢印キー、昼・夕暮れ・折り目・リセットで絵が変わる。
4. PNGを実取得し、開き具合・角度・時間帯と一致する。
5. 通常の動きと「動きを減らす」設定の両方で開閉し、途中で保存する。
6. 作り方のコピー内容が本文と一致し、戻った後も作品を操作できる。

制作担当はブラウザを操作せず、親担当がその画面と公開を所有しています。
