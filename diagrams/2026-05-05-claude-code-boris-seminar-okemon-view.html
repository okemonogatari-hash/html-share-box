📖 そもそも Claude Code って何？

**ターミナル（黒い画面）で動くAIアシスタント**。コードを書くだけじゃなくて、ファイルを調べたり、調べ物したり、Gitを操作したり、メールを下書きしたり、なんでも頼める。

1

まず「質問」だけしてみる

📅 今日やる / 5分

Claude Codeを開いたら、何かを作らせる前に「聞くだけ」から始めよう。これが一番の上達への近道、ってボリスも言ってる。Anthropicでは新人さんがコレやって、慣れる期間が2〜3週間→2〜3日になった。

▼ こう打ってみよう（コピーしてOK）
  • 質問例①
    このフォルダって何のプロジェクト？要約して
  • 質問例②
    このファイル、どこから呼ばれてる？
  • 質問例③
    ここ最近どんな変更があった？git logまとめて
  • 質問例④
    この関数、なんでこんなに引数多いの？git履歴から理由探して

💡 ポイント：いきなり「○○作って」じゃなく、まず「○○ってどうなってる？」。これだけで「あ、こいつ何ができるか分かってきた」感覚が掴める。

2

大きい仕事は「先に作戦聞いて」と言う

📅 今日やる / 1分で覚えられる

頼み方を 「○○して」→「○○したい、先に進め方教えて」 に変えるだけ。これでAIが暴走して見当違いのものを作っちゃう事故が激減する。

❌ いきなり頼む
ログイン機能を実装して
↓

↓
「想像と違う…」
全部書き直し
⭕️ 先に作戦を聞く
ログイン機能を作りたい。先にどう実装するつもりか教えて
↓
①メアド+PW認証 ②セッション管理は… ③DBテーブルは…
↓
「OK、進めて」
一発で意図通り ✨

💡 ポイント：「考えてから動いて」ってお願いするだけ。プランモード等の特別な機能は不要。

3

便利キー、3つだけ覚える

📅 明日やる / 体に染み込ませる

全部覚えなくていい。この3つだけ覚えれば作業速度が一気に上がる。

Shift + Tab

毎回の確認をスキップ

AIの編集を全部自動承認。テスト書かせる時とか便利

#

「これ覚えて」

#を打って文字書くと、AIが永続的に覚えてくれる

Esc

止まって・やり直し

AIが暴走したら即停止。2回押すと履歴に戻れる

💡 おまけ：! でターミナルコマンドが直接打てる、Ctrl+R でAIが見てる全画面を見せてくれる。

4

「うちの前提」をメモにまとめる（CLAUDE.md）

📅 今週中にやる / 15分

プロジェクトの根っこに CLAUDE.md ってファイルを置いとくと、AIが毎回最初に読んでくれる。「毎回これ説明するのめんどい」を全部ここに書いとく。

▼ 最低限こんな感じで書く
# このプロジェクトについて 社内向けAIアシスタント。Next.jsで作ってる。 # よく使うコマンド - npm run dev — 開発サーバー起動 - npm test — テスト実行 # 大事なルール - DBは触らないで（読み取りのみOK） - パスワード等は環境変数から取ること # 重要なファイル - src/lib/auth.ts — 認証の中枢

💡 ポイント：長くしすぎない。AIが毎回読むので、長いとトークン無駄にする。最初は10〜20行で十分。

5

慣れてきたら、同時に何個も動かす

📅 来週やる / 慣れてから

1個のClaude Codeじゃなくて、ターミナルを複数開いて並列で走らせる。1人がコード書いてる間に、もう1人がドキュメント書いてる、みたいな状態。

最初はターミナルのタブを2つ開いて、別々の作業を頼んでみる。慣れたらgit worktreeで複数の作業ブランチを並列で動かす、というのがプロの使い方らしい。

💡 ポイント：いきなりやらない。STEP 1〜4が体に染みてからでいい。

❓会場からのQ&A（全3問）
Q1. 作るときに一番難しかったのは？
「AIが命令を実行する時の安全装置」が一番難しかった。毎回確認すると面倒、勝手に動くと危ない。安全と便利のバランスをとる仕組み作りが大変だった。
Q2. 画像とか写真もAIに渡せる？
渡せます。最初から対応してます。①ドラッグ&ドロップ ②ファイルパスを渡す ③コピー&ペースト の3パターン全部OK。デザイン画像を渡して「これ作って」とよく使う。
Q3. AI研究そのものにも使ってる？
めちゃくちゃ使ってます。Anthropic社内では技術職の約8割が毎日Claude Code使ってる。研究者もエンジニアも両方。Jupyter Notebookも編集できる。

📝 1週間チャレンジ・チェックリスト

  • 初日：何か質問だけしてみる（コードに触らない）
  • 2日目：「先に作戦聞いて」を1回使ってみる
  • 3日目：Shift+Tab・#・Esc を1回ずつ使ってみる
  • 週末：CLAUDE.md を10行だけ書いてみる
  • 来週：ターミナル2つ開いて並列で動かしてみる
