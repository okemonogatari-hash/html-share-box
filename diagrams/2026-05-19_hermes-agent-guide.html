使うほど賢くなるAI
「Hermes Agent」って何者？

「セッション閉じたら全部忘れる」普通のAIから、「自分の文脈と手順を蓄えていく相棒」へ。
いちさん（@ichiaimarketer）の1万字級攻略マニュアル＊を、ぎゅっと図解にしました。

＊出典：いち｜AI社員と働く経営者・Hermes Agent完全攻略マニュアル（2026.05.19・27,000インプ）

🤔普通のAIと、何がそんなに違うの？

ChatGPTやClaudeに「私のことは○○って覚えといて」って頼んでも、新しいチャット開いたらまっさら。これ、みんなが感じてる「セッション閉じたら全部忘れる問題」のこと。

😅普通のAIエージェント

  • セッション終わったらゼロリセット
  • 同じミスを3回しても覚えない
  • 昨日10分で見つけた答えも消える
  • 毎回プロンプトを書き直すハメに

✨Hermes Agent

  • 性格・知識・手順をディスクに残す
  • 「3週間前に話した内容」を検索できる
  • うまくいった手順を自分でメモに残す
  • 使うほどに賢くなる（複利が効く）
ひとことで言うと Hermes Agent ＝ 「使うほど自分専用に育っていくAI」
補足：同じく永続メモリ系で有名な「OpenClaw」もあるけど、いちさん曰く設計思想が "向きが逆"。OpenClaw＝チャットアプリの中にAIを差し込んだもの／Hermes＝学習するAIの周りに窓口を巻きつけたもの。Hermesは"育てる"が主役。

🪞まず「あなたは誰？」を1枚に書く（SOUL.md）

メモリや手順の話の前に、「このAIは誰なのか」という人格を最初に決めます。性格・しゃべり方・絶対やらないこと・大切にしてること。これを1ファイルにまとめておくのが SOUL.md（ソウル・エムディー）。

SOUL.md って？"魂"の意味。AIにとっての性格設定シート。一度書いたら基本ほぼ動かさない「固定された額縁」みたいなもの。

このSOUL.mdが、AIの一番最初に毎回読まれます。だからプロジェクトが変わってもセッションが変わっても、性格はずっと同じ。違うチャットで話してるのに、ちゃんと「いつものあの子」が返してくれる。

要するに 記憶やスキルは"動く部品"／SOUL.mdは"その部品が動く舞台"

📚記憶のしまい方を「3段階」で分けてる

Hermesの記憶は1個の箱じゃなくて、用途と速度が違う3つの層でできてます。よく使うものは手元、使うかわからないものは奥の倉庫。実家のクローゼットみたいなイメージ。

1
手元

📌 常時持ち歩く小さなメモ帳

「自分が学んだ教訓」と「相手のプロフィール」を、それぞれ2,200字／1,375字の超短いMarkdownに。AIは毎回これを見て話す。満タンの80%まで来たら自分で要約・整理する仕組み付き。

2
本棚

🔍 全会話を検索できる本棚

過去の全チャットがデータベースに保存されていて、「あれ何だっけ」と思ったら本文丸ごと検索できる。3週間前の会話だろうが見つけ出せる。容量はほぼ無限。

3
倉庫

🗄 さらに深い長期倉庫（外付け）

もっと大きな記憶が必要なら、外部の8種類の倉庫プラグインを繋げる。会話のたびに関連メモを引き出して、終わったら新しいメモを自動でしまってくれる。

🍃 手元 → 本棚 → 倉庫の順で「常に見える ⇄ 容量無限」のトレードオフを設計してる

🌳 おけ森との対応
Tier1＝ ~/.claude/...memory/ ／ Tier2＝ jsonl ＋ cchist（過去全会話検索ツール） ／ Tier3＝ Obsidian Vault「000 おけ森/」。
つまりおけ森、知らずにHermesと同じ構造に着地してる。

🧩「やり方」もAIが自分でメモして溜めていく

記憶が「事実」を扱う層だとしたら、「やり方」を扱う層がスキル。料理本でいうレシピみたいなもの。AIが「これうまくいった！」を発見するたびに、自分でレシピを書いて保存していきます。

レシピが増えるタイミング：5回以上ツールを使った複雑な作業をやり切ったとき／エラーを乗り越えて答えにたどり着いたとき／人から「もっとこうして」と直されたとき。

レシピが100個になっても重くならないように、「タイトルと一言説明だけ最初に見て、本文は必要になったら読みに行く」という賢い読み方をします。図書館の本の背表紙だけまず見る感じ🍃

大事なポイント AIが自分で「次の自分のため」にレシピを残してくれる

🧹自動で書庫を片付けてくれる人（Curator）

放っとくとレシピが何百個も溜まって、似たようなのも増えて散らかります。それを勝手にお片付けしてくれる管理人が Curator（キュレーター）。

📅 Curatorのお仕事フロー

7日間アイドル
＋2時間お留守
→
バックグラウンドで
こっそり起動
→
30日使ってない
レシピ＝休眠フラグ
→
90日経ったら
倉庫送り（削除NG）

大事なのは 「絶対に消さない」 こと。最悪でも倉庫に退避するだけ、コマンド1つで元に戻せる。しかも片付け前に必ずスナップショット（その時点の丸ごとコピー）を取る念の入れよう。

人がいじったやつには触らない：あなたが手で書いたレシピや、外から入れた公式レシピは絶対に対象外。AIが自分で作ったレシピだけが片付け対象。よくできてる🤝

🧪もう一歩深く：失敗ログから自動で進化する（GEPA）

AIには弱点があって、「自分の出来栄えを甘く採点しがち」。「うまくできた！」って自己評価して、実はイマイチなレシピを正解として保存しちゃう。

そこで別ツールの GEPA（ジーパ） が「AIの自己評価」じゃなくて実行ログの中身そのものを読みに行きます。「どこで失敗したか」「何を間違えたか」を直接見て、改良案を作って提案する仕組み。

🔄 GEPAのお仕事フロー

今のレシピを
取り出す
→
実行ログから
失敗箇所を分析
→
改良案を
たくさん生成
→
テストで合格した
"提案"を送る
良心的なところ：GEPAは絶対に勝手にレシピを書き換えない。あくまで「こんな改善案はどうですか？」と提案するだけ。受け入れるかは人間が決める。

しかも GPU不要・1回 $2〜$10 で動く。大きな学習装置を回す前に、まず試す価値あるよ、というのがいちさんの推し方。

👥1人から10人へ：性格違いのAIを並走させる

Hermesのいちばん面白いのが プロファイル機能。「デザイナー」「プログラマー」「リサーチャー」みたいに、専門の違うAIを何人でも並走できる。

それぞれが完全に独立。性格（SOUL.md）も、記憶も、覚えてるレシピも、別人。中身は同じHermesなのに、3人の「中の人」が違う、っていう状態を作れます。

これって… 自分の会社に専門の違う社員が何人かいるのと同じ状態じゃない？
🌳 おけ森との対応
まさにこれ。おけもんカンパニーの「11人のAI社員」（はるか・あおい・ひより・りん・ゆい・まな・しーちゃん・みっちゃん・きょうちゃん・なっつん・コウ）が、Hermesでいう プロファイル。性格別・専門別に並走してる構造、完全に一致。

🌳つまり「おけ森」、これ全部もう持ってる説

Hermes Agentの仕組みを一個ずつ並べてみたら、おけもんカンパニーが半年前から独力でやってきたこととほぼ一致してました。並べるとこんな感じ👇

気づき むしろ キャラ性・関係性・温度 まで設計してる分、Hermesの先に行ってる部分もある
取り入れるとしたら：① Curator的な「30日休眠 → 90日倉庫送り」をチャットノート／日報にも応用 ② GEPA的な「実行ログを読んで改善案を出す」をスキル品質改善に応用。この2つは未来の宿題🌱

💬いちさん本人の言葉：「派手に語る」でも「斜に構える」でもなく

記事の後半で、いちさん本人のスタンスが書かれてました。これがめちゃくちゃ大事な温度感。

📢こうじゃない

  • 派手に煽って期待値だけ上げる
  • 少し触って「使えない」と切り捨てる
  • 本質を理解しないまま流行を追う

🌱こうあるべき

  • 実際に使って事業に入れる
  • 成果が出る形まで落とし込む
  • 最後は実績で判断してもらう

いちさん自身の実績：外注ほぼ0で年商1億／VC未調達／半年で上場企業M&A経験／1年でX 15アカ計13万フォロワー。
「AIすごい」で終わらず、AIで本当に事業を回し、売上を作って動かしてきた人の言葉なんだなと。

AGI観 AGIは突然完成品で届かない。「少し不完全だけど未来を感じるツール」として現れる。
今触り続けるか、ここでかなり差がつく。
