🧙 AI仙人ライブまとめ

AIで人生変わる人って、
どんな人？

実際に見てきた人たちの「5つの共通項」

📺 元動画を見る（51分）

🤔 こんな違和感、ありませんか？

AIってめっちゃ流行ってるけど、結局忙しい時は自分でやった方が早いから、本当に人生変わってる人っていなくない？

…と思ったら、AI仙人いわく 「いやいや、変わりまくりや」。

では、AIで本当に人生が変わってる人って何が違うのか。共通してるのはこの5つでした👇

1

欠けてる部分が多い人

AIは「弱みを80点まで持ち上げる装置」

AIが一番得意なのは、実はマイナスをプラスに変えること。「100を110にする」のは天才の仕事だけど、「10しかできないことを80にする」のはAIめちゃくちゃ得意。

EXAMPLE デザイナーさんが、自分の売り出し方をずっとAIと壁打ち。気づいたら、アイデア出し→お客さん獲得→デザインの上流〜下流まで、全部AIで回せるようになって、1人で1法人を回す動き方ができるように。
EXAMPLE 会社経営してるのにお金の計算が苦手だった人が、月の支出・残しておくべき金額・次の入りを計算するツールをClaude Codeで自作。「目立って儲かった」じゃないけど影でめっちゃ役立つ結果に。
マイナスをよく見るタイプの人と、AIは相性がいい。トップ伸ばしたいなら人間の手をかけないとダメだけど、足を引っ張ってる弱いところ補うならAI余裕。
👉 自分ごと化チェック
「あれが苦手で足を引っ張ってる」って自覚があるところ、いくつ思い浮かぶ？多いほど、AIで一気に世界が広がる可能性が大きい。
2

コンテキストめっちゃ持ってる人

AIに渡せる「自分の情報」をどれだけ集めてるか

コンテキスト＝AIに放り込む情報全部のこと。仕事のやり方・判断基準・過去の経験…全部。仙人いわく 「仕事の質＝コンテキストの質」。

そして大事な事実：あなた自身のコンテキストが一番強い。「孫正義さんやイーロンマスクのコンテキストの方が強くない？」って聞かれるけど、答えはNO。情報の密度が分からないし、自分が知ってるものじゃないと足りない。

EXAMPLE 仙人本人は「コンテキストオタ」。パソコンの作業ログ全部録画＋スクショ、AIに渡せる素材を常時ストックしてる。
こんな副産物も コンテキストを集めてAIと喋り続けると、普段スルーしてる自分の無意識にアクセスできる。「見やすい分析 vs 正しい分析」みたいな食い違いをAIが指摘してくれて、自分の判断基準が初めて言語化される。
AIを使いこなしてる人と、こなせない人の差は、マジでこれしかない。「自分の仕事をどれだけ言語化できてるか」やね。
👉 自分ごと化チェック
AIに「自分のこと」をどれくらい伝えてる？仕事のやり方・判断基準・過去の経験…全部渡せるくらい話してる？
3

AIに挑戦させる人

「ゴールだけ渡す」が新時代の使い方

これまでは「具体的に手順を細かく指示する」のが正解とされてた（AIは新卒社員みたいなもんだから）。でも Opus 4.7 以降、「何も言わずゴールだけ渡す」方が良いって言われ始めた。

理由：AIの質が上がりすぎて、AIが考える手順の方が人間より質が高い場面が増えたから。

EXAMPLE ある経営者の話。AIもプログラムも何も分からないけど、AIが好きすぎて画面に10個くらいClaude Codeを開いて1ヶ月喋り続けた。Claude Codeの課金切れたらCodexに切り替えてまた死ぬほど触る。結果、世界でも有数なマイナー分野のシステムが完成した。
変に自分の脳内で閉じない方がいい。世界中の情報を食らってるAIが「一番いい」と思った方法を判定してくれる。自分の発想の外に出れる。

ただし注意：自分のドメイン知識（仕事の領域）の周辺で使うこと。全くチャレンジしたことない領域でAI丸投げは、出てきたものを評価できなくて死ぬ。

👉 自分ごと化チェック
自分の得意分野でも、あえて手順を教えずに「ゴールだけ」渡してみる。固執してた「自分のやり方」が更新されるかも。
4

何もなかった人

時間だけはある人が、AIに全振りすると人生変わる

「強みでやりなさいって言うけど、私には強みがないんです…」って人へ、仙人の答えは 「お前はAIをやれ」。

理由：AIは今、世界中で一番お金が流入してる領域。何十兆円が動いてるし、「AI使える人を育てなあかん」がどこの会社でも合言葉。需要が爆発的に高い。

そして驚きのデータ：
AIエージェントを使ったことがある人は、上位3%しかいない。

EXAMPLE 設定方法が分かるだけで仕事になる。仙人の友達も「セットアップだけ教えて数万円もらえてびっくりした」と話してる。
EXAMPLE 情報商材で「AI詳しい人コミュニティ最強」みたいなのが出ても、機械学習やってた本物のAI技術者は誰も入ってない。新しい領域だからみんなスタート地点が同じ＝極めてる人がまだ少ない。
「今の仕事があってAI勉強する時間ない」って人より、「今何もないです、時間だけはあります」って人の方が、AIに全振りできて圧倒的に有利。
👉 自分ごと化チェック
時間だけはある時期＝AIに振り切る最大のチャンス。「何もない」は、AIをやる絶対条件のひとつ。
5

AIを使ってることを声高らかに叫ぶ人

「好き」を周りに伝えるところから人生は変わり始める

これが1番最後にして1番効く共通項、と仙人。AIで何か作っても、なぜかみんな黙ってる。「自分なんて」「こんな簡単に作れたら誰でもできるやん」って。

でも、上位3%しかAIエージェント触ってない時代に、「AIで作りました」を言うだけで、リアルでは差し伸べられる手が結構ある。

EXAMPLE 動画のインタビュアーさん（AI専門ではない）が、自分の会社のホームページをAIで作って友達に「AIでサイト作ってみた」って言っただけ。そしたら周りで「AI詳しい人」判定されて、AI導入コンサルの依頼が舞い込むように。
100人に伝えたら1人くらいは仕事になる。リアルで言うのが結局一番早い。ネット案件は競争激しすぎる。

ポイント：売り込みじゃなくて「好きを伝える」だけでOK。「これおもろいんですよ」って楽しそうに話す。それで人が運んできてくれる。

👉 自分ごと化チェック
最近作ったもの、誰かに見せた？「自分なんて」って黙ってると、せっかくの上位3%が誰にも届かない。

＋α 最新ツールに即答できること

「AI好きです！」って叫んだ後に絶対聞かれる質問が 「で、今どのAIがいいの？」。これに即答できないと「お前ほんまにAI好きなんか…」と詰められて死ぬ。

ホームページ作るならGPT、コード書くならClaude Code or Codex、会議の文字起こしならCircleback…分野ごとに「今のおすすめ」を言えるようにしておくのが、5つ目を活かす上での前提条件。

🌟 5つを並べてみると…

欠けてる人が、コンテキストを集めて、ゴールを渡してAIに挑戦させ、時間を投下し、声に出して伝える。

これって 「AIを使う」 って話じゃなくて、「AIと一緒に生きる」 って話。

歯磨く 🪥　顔洗う 🧖　ご飯食べる 🍚　
AIと喋る 🗣

必要な時だけAIを呼び出すんじゃなくて、日常の中にAIがいる状態。
仲良くなるから自然とコンテキストが溜まる。

🚀 で、自分は何から始める？

  1. 欠けてるところリストを書き出す — 自分が「これ苦手」って自覚してる作業を3つ書く
  2. AIに自分のことを話す習慣をつける — 仕事の判断基準・好み・過去の経験。気づいたら無意識が言語化される
  3. 1つだけゴールを渡してみる — 手順を指示せず「これ作って」だけ。出てきたものを見る
  4. 作ったものを誰か1人に見せる — 友達でも兄弟でもOK。「AIでこんなん作れた」って楽しそうに言うだけ
  5. 「今のおすすめAI」を1つだけ言えるようにする — 全部覚えなくていい。1ジャンルだけでいい
