第2章

おけ森が今やれる/やれない切り分け

議論の前提として、現在のおけ森ができる/できない広告運用領域の境界線を一旦明文化する。

今やれる

  • HPにGA4/Clarityを仕込む（既存技術・無料ツール）
  • **自社のIG広告・X広告アカウント開設**（おけちゃん本人広告主・デビット決済）
  • **自社広告の小口出稿**（週¥3,000〜5,000）
  • **広告クリエイティブ（静止画・LP）生成**（Claude Code＋Canva＋Suno）
  • **週次レビュー＋仮説提案**（Claude Code + Codex MCP 並列）
  • **クライアント広告アカウントを read-only で観察**（GA4 / Google Ads MCP 公式）
  • **ケーススタディ匿名化記事化**（許諾取得後）

今やらない

  • **媒体費の立替・カード代行**（現状の固定費制約下・デビット即時引落のみ）
  • **広告アカウント代理運用**（write権限を握る）
  • **広告成果保証**（CVR/ROAS固定保証）
  • **クライアント予算判断の代行**
  • **大規模媒体予算運用**（実績ゼロ）
  • **「広告運用代行業者」を名乗る**（昨日Day0623-2着地で却下済）
