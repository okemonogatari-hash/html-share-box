はじめてのVTuberデビュー用

VTuber開始キット

ChatGPTで作った立ち絵1枚と、自分で撮った録画の声。この2つから、キャラクターが声に合わせて口パク・まばたきしながらしゃべる縦動画（1080×1920）ができるキットです。下の「Claude Codeにまるごと渡す」を1回コピーして貼れば、あなたのClaude Codeがそのまま作れます。

01しくみ

Live2Dのような骨組みは使いません。立ち絵に「口の差分」と「閉じ目」を描き足して、声の大きさで絵を切り替えるだけ（PNGTuber式と呼ばれるやり方）です。

立ち絵1枚口を閉じた正面の絵。背景は単色
差分6枚口（閉じ・半開き・全開）× 目（開き・閉じ）を道具が描き足す
声で切り替え1/30秒ごとの声の大きさで口を選ぶ。まばたき・呼吸のゆれ・話す時の弾みも自動
  • 口は「開くのは速く、閉じるのは少しゆっくり」動かすと、ぱくぱくが自然に見えます
  • まばたきは2.4〜4.2秒おきにランダム。最後は閉じ目のにっこりで締めます
  • 字幕は台本テキストがあれば付きます。声のある区間に文字数の比で割り振る目安なので、少しずれることがあります

02あなたがやること

あなた

① ChatGPTで立ち絵を1枚作る

ChatGPTにこの頼み文を貼って作ってもらいます。キャラの中身は自由に書き換えてOK。口を閉じている・正面向き・背景が模様なしの単色・縦長の4つだけは残してください（道具が口と目を描き足しやすくなります）。

ChatGPTへの頼み文
VTuberの立ち絵を1枚作ってください。画像ファイル usagi_base.png として保存してください。

キャラ：ビジネス界隈の「あるある」に毒を吐く、最高にかわいい白うさぎの女の子（うさぎそのものの姿。人間ではない）。
- ふわふわの白い毛、長い耳（片耳だけ少し折れている）、ほっぺはピンク
- 小さな紺のジャケットと白シャツ、細い赤ネクタイ（ビジネス感）。片手に小さなコーヒーカップ
- 表情：かわいいのに目がちょっと据わっている「わかってますよ？」の半目気味のにっこり。口は閉じた小さな口
- 正面向き、上半身（胸から上）。顔は画面中央やや上、大きめ
- アニメ／Live2D風のきれいな線と塗り。影は控えめ
- 背景は真っ平らな薄いミントグリーン単色（あとで合成するので模様なし）
- 縦長 1024x1536
- 文字・ロゴは入れない

② 録画を撮る

  • スマホやPCで、しゃべっている所を撮るだけ（顔は映らなくてOK。使うのは声だけ）
  • 静かな部屋で、マイクに近めに。BGMは入れない方が口の動きがきれいに合います
  • 字幕を出したい時は、しゃべった台本をテキストファイルで保存しておきます

③ Claude Codeに渡す

立ち絵・録画・台本を1つのフォルダに入れて、下の「まるごと」をコピー。［　］の所を自分のファイルの場所や題名に書き換えて、Claude Codeに貼ります。

頼み文＋道具2本（まるごと）
VTuberの口パク動画を作りたいので、手伝ってください。

■ ゴール
私の立ち絵（ChatGPTで作った1枚）が、私の録画の声に合わせて口パク・まばたきしながらしゃべる縦動画（1080×1920のmp4）ができていること。

■ 材料
・立ち絵：［立ち絵の画像のパス］
・録画：［録画のパス（mp4・mov・m4a など）］
・台本：［台本テキストのパス。無ければ「なし」＝字幕なし］
・動画の上の帯：小見出し「［あなたの番組名の］」／題名「［タイトル］」／帯の下の一行「［第1話｜会議のための会議］」
・最後に出すひと言：「［チャンネル登録してね］」（いらなければ空）
・道具：このあとに貼る make_parts.py と render.py。作業フォルダの tools/ にそれぞれ保存して使う

■ 進め方の目安
1. python3・Pillow・numpy・ffmpeg があるか確かめ、無ければ入れる
2. 立ち絵の大きさを確かめ、`python3 tools/make_parts.py grid 立ち絵 左 上 右 下 grid.png` で口元と目のあたりを方眼つきで切り抜く。その画像を自分の目で見て、閉じた口の真ん中の座標と、左右の目の範囲（まつげの先まで）を読み、face.json に書く（書き方は make_parts.py の先頭の説明）
3. `python3 tools/make_parts.py make 立ち絵 face.json parts` で差分6枚を作る。parts/check.png を見て、口が口の位置から開いているか、閉じ目が目の位置に乗って元の目が消えているかを確かめる。ずれていたら face.json を直して作り直す。口が小さすぎ・大きすぎなら mouth.size で調整する
4. `python3 tools/render.py --voice 録画 --parts parts --out 出来上がり.mp4 --script 台本 --kicker 小見出し --title 題名 --note 下の一行 --end 最後のひと言` で書き出す

■ 終わりの条件
・mp4 が再生でき、声が入っている
・書き出した動画から、しゃべっている所と黙っている所のコマを数枚切り出して見て、しゃべっている時に口が開き、黙っている時に閉じている
・題名と字幕の文字が化けていない
・できた動画の場所と、使った face.json の数字を私に教える

「まるごとコピー」には、上の頼み文に続けて make_parts.py と render.py の全文が入ります。中身は下の04で見られます。

04道具2本

make_parts.py（立ち絵から差分6枚を作る）

新しい立ち絵では、口と目の位置が絵ごとに違います。grid で口元と目のあたりを方眼つきで拡大し、画像を見て座標を読み、face.json に書きます。

tools/make_parts.py
"""立ち絵1枚から、口パク3段階 × 目の開き/閉じ の6枚を描く（PNGTuber式）。

使い方:
  # 1) 座標を読むための方眼つき拡大図を作る（口元・目のあたりを切り抜いて見る）
  python3 make_parts.py grid 立ち絵.png 左 上 右 下 出力.png
  # 2) 座標を face.json に書いて、6枚を作る（確認用の並べ図 check.png も出る）
  python3 make_parts.py make 立ち絵.png face.json 出力フォルダ

face.json の例（数字は元の立ち絵のピクセル座標。左上が 0,0）:
{
  "mouth": {"x": 518, "y": 901, "size": 1.0},
  "eyes": [[196, 712, 446, 856], [578, 712, 828, 856]],
  "remove_bg": true
}
  mouth.x, mouth.y : 閉じた口の真ん中（ω の合わせ目など、口が開く起点）
  mouth.size       : 口の大きさの倍率。顔が大きい絵は 1.3、小さい絵は 0.7 など
  eyes             : 左目・右目それぞれの [左, 上, 右, 下]。まつげの先まで含めて囲む
  remove_bg        : 背景が単色なら true（四隅の色を透明にする）
  skin / line      : 省略可。肌（毛）の色・線の色を [R,G,B] で。省略時は肌は目と目の間から自動で拾う
"""
import json
import os
import sys

import numpy as np
from PIL import Image, ImageDraw, ImageFilter, ImageFont

SS = 4  # 4倍で描いて縮める（線をなめらかに）


def S(v):
    return int(round(v * SS))


def overlay(base, draw_fn, box):
    x0, y0, x1, y1 = [int(v) for v in box]
    x0, y0 = max(0, x0), max(0, y0)
    x1, y1 = min(base.width, x1), min(base.height, y1)
    w, h = x1 - x0, y1 - y0
    layer = Image.new("RGBA", (w * SS, h * SS), (0, 0, 0, 0))
    draw_fn(ImageDraw.Draw(layer), x0, y0)
    layer = layer.resize((w, h), Image.LANCZOS)
    out = base.copy()
    out.alpha_composite(layer, (x0, y0))
    return out


def mouth_fn(cfg, level, line):
    m = cfg["mouth"]
    s = m.get("size", 1.0)

    def fn(d, ox, oy):
        cx, top = m["x"] - ox, m["y"] - oy
        w = {1: 16, 2: 24}[level] * s
        h = {1: 18, 2: 40}[level] * s
        lw = max(1.5, 3 * s)
        # 口の中（閉じた口の真ん中から下へ垂れる、まるい口）
        d.chord([S(cx - w), S(top - h), S(cx + w), S(top + h)], 0, 180, fill=(125, 32, 48), outline=line, width=S(lw))
        # 舌
        tw = w * 0.7
        d.chord([S(cx - tw), S(top + h * 0.35), S(cx + tw), S(top + h * 1.55)], 180, 360, fill=(242, 128, 148))
        d.chord([S(cx - w), S(top - h), S(cx + w), S(top + h)], 0, 180, outline=line, width=S(lw))

    return fn


def mouth_box(cfg):
    m = cfg["mouth"]
    s = m.get("size", 1.0)
    return (m["x"] - 100 * s, m["y"] - 61 * s, m["x"] + 100 * s, m["y"] + 79 * s)


def blink(base, cfg, skin, line):
    out = base.copy()
    mask = Image.new("L", base.size, 0)
    md = ImageDraw.Draw(mask)
    for (x0, y0, x1, y1) in cfg["eyes"]:
        pad = (x1 - x0) * 0.072
        md.ellipse([x0 - pad, y0, x1 + pad, y1], fill=255)
    mask = mask.filter(ImageFilter.GaussianBlur(6))
    fill = Image.new("RGBA", base.size, tuple(skin) + (255,))
    out = Image.composite(fill, out, mask)
    out.putalpha(base.getchannel("A"))
    xs = [v for e in cfg["eyes"] for v in (e[0], e[2])]
    ys = [v for e in cfg["eyes"] for v in (e[1], e[3])]
    box = (min(xs) - 40, min(ys) - 20, max(xs) + 40, max(ys) + 20)
    left_x = min(e[0] for e in cfg["eyes"])

    def lids(d, ox, oy):
        for (x0, y0, x1, y1) in cfg["eyes"]:
            w, h = x1 - x0, y1 - y0
            # 下向きのまるい弧＝にっこり閉じ目
            d.arc([S(x0 + 0.136 * w - ox), S(y0 + 0.23 * h - oy), S(x1 - 0.136 * w - ox), S(y0 + 0.78 * h - oy)],
                  20, 160, fill=line, width=S(max(2, 0.032 * w)))
            # まつげの跳ね（外側に向ける）
            if x0 == left_x:
                a, b = (x0 + 0.196 * w, y0 + 0.61 * h), (x0 + 0.084 * w, y0 + 0.5 * h)
            else:
                a, b = (x1 - 0.196 * w, y0 + 0.61 * h), (x1 - 0.084 * w, y0 + 0.5 * h)
            d.line([(S(a[0] - ox), S(a[1] - oy)), (S(b[0] - ox), S(b[1] - oy))], fill=line, width=S(max(2, 0.024 * w)))

    return overlay(out, lids, box)


def remove_bg(base):
    arr = np.array(base).astype(float)
    corners = np.concatenate([arr[:20, :20, :3].reshape(-1, 3), arr[:20, -20:, :3].reshape(-1, 3)])
    bgc = np.median(corners, axis=0)
    dist = np.sqrt(((arr[:, :, :3] - bgc) ** 2).sum(axis=2))
    alpha = np.clip((dist - 14) / 22, 0, 1) * 255
    key = Image.fromarray(alpha.astype("uint8")).filter(ImageFilter.MinFilter(3)).filter(ImageFilter.GaussianBlur(0.8))
    base.putalpha(key)
    return base


def cmd_make(img_path, cfg_path, outdir):
    cfg = json.load(open(cfg_path, encoding="utf-8"))
    base = Image.open(img_path).convert("RGBA")
    rgb = Image.open(img_path).convert("RGB")
    if cfg.get("remove_bg", True):
        base = remove_bg(base)
    (lx0, ly0, lx1, ly1), (rx0, ry0, rx1, ry1) = sorted(cfg["eyes"])[:2]
    skin = cfg.get("skin") or list(rgb.getpixel((int((lx1 + rx0) / 2), int((ly0 + ly1) / 2))))
    line = tuple(cfg.get("line") or (70, 30, 38))
    os.makedirs(outdir, exist_ok=True)
    made = []
    for eye in ("open", "closed"):
        b = base if eye == "open" else blink(base, cfg, skin, line)
        for lv in (0, 1, 2):
            img = b if lv == 0 else overlay(b, mouth_fn(cfg, lv, line), mouth_box(cfg))
            p = os.path.join(outdir, f"{eye}_m{lv}.png")
            img.save(p)
            made.append(img)
    # 確認用：顔のあたりを6枚並べる（上段＝目あき、下段＝目とじ、左から口 閉じ/半開き/全開）
    xs = [v for e in cfg["eyes"] for v in (e[0], e[2])] + [cfg["mouth"]["x"]]
    ys = [v for e in cfg["eyes"] for v in (e[1], e[3])] + [mouth_box(cfg)[3]]
    crop = (max(0, min(xs) - 60), max(0, min(ys) - 60), min(base.width, max(xs) + 60), min(base.height, max(ys) + 40))
    tiles = []
    for im in made:
        t = Image.new("RGB", im.size, (255, 255, 255))
        t.paste(im, mask=im.getchannel("A"))
        tiles.append(t.crop(crop))
    W, H = tiles[0].size
    sheet = Image.new("RGB", (W * 3, H * 2), "white")
    for i, t in enumerate(tiles):
        sheet.paste(t, ((i % 3) * W, (i // 3) * H))
    sheet.save(os.path.join(outdir, "check.png"))
    print("ok: 6枚と check.png を", outdir, "に保存。肌の色", skin)


def cmd_grid(img_path, x0, y0, x1, y1, out):
    x0, y0, x1, y1 = int(x0), int(y0), int(x1), int(y1)
    im = Image.open(img_path).convert("RGB").crop((x0, y0, x1, y1))
    k = 2
    im = im.resize((im.width * k, im.height * k), Image.LANCZOS)
    d = ImageDraw.Draw(im)
    try:
        font = ImageFont.truetype("/System/Library/Fonts/Supplemental/Arial.ttf", 16)
    except OSError:
        font = ImageFont.load_default()
    step = 25
    for x in range((x0 // step + 1) * step, x1, step):
        major = x % 100 == 0
        d.line([((x - x0) * k, 0), ((x - x0) * k, im.height)], fill=(0, 120, 255) if major else (150, 200, 255), width=2 if major else 1)
        if x % 50 == 0:
            d.text(((x - x0) * k + 2, 2), str(x), fill=(0, 60, 200), font=font)
    for y in range((y0 // step + 1) * step, y1, step):
        major = y % 100 == 0
        d.line([(0, (y - y0) * k), (im.width, (y - y0) * k)], fill=(255, 60, 60) if major else (255, 170, 170), width=2 if major else 1)
        if y % 50 == 0:
            d.text((2, (y - y0) * k + 2), str(y), fill=(200, 0, 0), font=font)
    im.save(out)
    print("ok:", out, "（青い線＝x、赤い線＝y。数字は元の立ち絵の座標）")


if __name__ == "__main__":
    if len(sys.argv) >= 2 and sys.argv[1] == "grid" and len(sys.argv) == 8:
        cmd_grid(*sys.argv[2:])
    elif len(sys.argv) >= 2 and sys.argv[1] == "make" and len(sys.argv) == 5:
        cmd_make(*sys.argv[2:])
    else:
        print(__doc__)
        sys.exit(1)

render.py（声で口パクさせて縦動画にする）

tools/render.py
"""録画（または録音）の声の大きさで、立ち絵に口パク・まばたき・ゆれを付けて縦動画（1080x1920）にする。

使い方:
  python3 render.py --voice 録画.mp4 --parts 差分フォルダ --out 出来上がり.mp4 \
      --title "ビジネスあるある" --kicker "毒舌うさぎの" --note "第1話｜会議の前の会議" \
      --script 台本.txt --end "チャンネル登録してね"

  --voice   声の入った録画か録音（mp4/mov/m4a/wav など。ffmpeg が読める物なら何でも）
  --parts   make_parts.py make で作ったフォルダ（open_m0.png 〜 closed_m2.png）
  --script  台本テキスト。あれば字幕を出す（声のある区間に文字数の比で割り振る目安）。無ければ字幕なし
  --title / --kicker / --note  上の帯の大きい題名・その上の小見出し・帯の下の小さい一行。空なら出さない
  --end     最後の2秒に出すひと言。空なら出さない
必要な物: python3, Pillow, numpy, ffmpeg
"""
import argparse
import math
import os
import random
import re
import subprocess
import sys

import numpy as np
from PIL import Image, ImageDraw, ImageFont

ap = argparse.ArgumentParser()
ap.add_argument("--voice", required=True)
ap.add_argument("--parts", required=True)
ap.add_argument("--out", required=True)
ap.add_argument("--script", default="")
ap.add_argument("--title", default="")
ap.add_argument("--kicker", default="")
ap.add_argument("--note", default="")
ap.add_argument("--end", default="")
ap.add_argument("--tail", type=float, default=2.0, help="声のあとに足す秒数")
ap.add_argument("--seed", type=int, default=7, help="まばたきの間隔の乱数")
args = ap.parse_args()

FPS, W, H, SR = 30, 1080, 1920, 24000


def find_font(cands):
    for p in cands:
        if os.path.exists(p):
            return p
    return None


# Mac はヒラギノ。無ければ Noto Sans CJK などを探す
BOLD = find_font(["/System/Library/Fonts/ヒラギノ角ゴシック W8.ttc", "/System/Library/Fonts/ヒラギノ角ゴシック W6.ttc",
                  "/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc", "/usr/share/fonts/noto-cjk/NotoSansCJK-Bold.ttc",
                  "C:/Windows/Fonts/meiryob.ttc", "C:/Windows/Fonts/YuGothB.ttc"])
MARU = find_font(["/System/Library/Fonts/ヒラギノ丸ゴ ProN W4.ttc", "/System/Library/Fonts/ヒラギノ角ゴシック W4.ttc",
                  "/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc", "/usr/share/fonts/noto-cjk/NotoSansCJK-Regular.ttc",
                  "C:/Windows/Fonts/meiryo.ttc", "C:/Windows/Fonts/YuGothM.ttc"]) or BOLD
BOLD = BOLD or MARU
if not BOLD:
    sys.exit("日本語フォントが見つからない。find_font の候補に、手元の日本語フォント（.ttc/.ttf/.otf）のパスを足してください")


def font(path, size):
    return ImageFont.truetype(path, size)


# --- 声を読む ---
raw = subprocess.run(["ffmpeg", "-v", "error", "-i", args.voice, "-vn", "-f", "s16le", "-ac", "1", "-ar", str(SR), "-"],
                     capture_output=True).stdout
if not raw:
    sys.exit("声が読めなかった。--voice のファイルに音が入っているか、ffmpeg が入っているかを確かめてください")
a = np.frombuffer(raw, np.int16).astype(float) / 32768
dur = len(a) / SR
TAIL = args.tail
N = int((dur + TAIL) * FPS)

# --- 口の開き：1コマごとの音量 → 0/1/2 ---
hop = SR // FPS
rms = np.array([np.sqrt(np.mean(a[i * hop:(i + 1) * hop] ** 2)) if (i + 1) * hop <= len(a) else 0 for i in range(N)])
ref = np.percentile(rms[rms > 0], 95)
env, lv, e = [], [], 0.0
for v in rms / ref:
    e = v if v > e else e * 0.55 + v * 0.45  # 開くのは速く、閉じるのは少しゆっくり
    env.append(e)
for v in env:
    lv.append(0 if v < 0.16 else 1 if v < 0.48 else 2)
for i in range(1, N - 1):  # 1コマだけ閉じるチラつきを消す
    if lv[i - 1] == lv[i + 1] != lv[i] and lv[i] == 0:
        lv[i] = lv[i - 1]

# --- まばたき：2.4〜4.2秒おきに4コマ ---
random.seed(args.seed)
blink = set()
t = 1.2
while t < dur + TAIL:
    f = int(t * FPS)
    blink.update(range(f, f + 4))
    t += random.uniform(2.4, 4.2)

# --- 字幕：声のある区間に、文字数の比で台本を割り振る（目安） ---
subs = []
if args.script and os.path.exists(args.script):
    text = re.sub(r"\s+", "", open(args.script, encoding="utf-8").read())
    chunks = [c for c in re.split(r"(?<=[、。！？!?])", text) if c]
    lines, buf = [], ""
    for c in chunks:  # 1枚の字幕は 9〜24文字ほど
        if len(buf) + len(c) > 24 and buf:
            lines.append(buf)
            buf = c
        else:
            buf += c
        if len(buf) > 14 and buf.endswith(("。", "、", "！", "？", "!", "?")):
            lines.append(buf)
            buf = ""
    if buf:
        lines.append(buf)
    win = int(SR * 0.05)
    sv = np.array([np.sqrt(np.mean(a[i:i + win] ** 2)) for i in range(0, len(a) - win, win)])
    speaking = sv > np.percentile(sv, 90) * 0.12
    sp_t = np.cumsum(speaking) * 0.05  # 経過した「声のある秒」
    total = sum(len(l) for l in lines)
    acc = 0
    for l in lines:
        s_sp = sp_t[-1] * acc / total
        acc += len(l)
        e_sp = sp_t[-1] * acc / total

def wrap(s, f, maxw):
    out, cur = [], ""
    for ch in s:
        if f.getlength(cur + ch) > maxw:
            out.append(cur)
            cur = ch
        else:
            cur += ch
    if cur:
        out.append(cur)
    return out
