基本が終わったら、次にできること

ここから先は、パスワードの基本を使えるようにしたあとで大丈夫です。

免許証・旅券・年金・保険などの番号をしまう

番号を書き込む前に、1Passwordの追加画面にある種類を選びます。運転免許証は Driver License、旅券は Passport、銀行口座は Bank Account、カードは Credit Card、書類ファイルは Document、種類が合わない保険・年金・契約番号は Secure Note などを候補にします。日本のマイナンバーや年金番号に、米国向けの Social Security Number 型が公式対応しているとは限りません。種類に迷ったら、番号を入力する前に公式の項目一覧を確認してください。原本と照らし合わせて保存し、番号をこのページやAIチャットへ書かないでください。

Codex・Claude Codeに開発用のキーを渡す

これはブラウザのログイン補助ではありません。1Passwordの開発用 Environment は「開発に使うキーをまとめる箱」、MCP は「AI開発ツールとその箱をつなぐ接続口」です。1PasswordはCodexとClaude CodeのローカルMCP連携を案内していますが、まず基本の移行を終えてから、MacまたはLinuxのデスクトップアプリで対応状況を確認します。Windowsで同じ手順が使えるとはここでは案内しません。

画面で1Passwordの Developer 設定と、利用するAIツールの接続設定が実際に見えるかを先に確認します。最初はダミーのキーだけで試します。MCPが値を直接返さなくても、承認後にマウントしたファイルは1Passwordをロック、またはマウントを止めるまで他のプロセスから読めることがあります。実際のキーを画面・チャット・ログへ出さないでください。Codex/Claude CodeのAPIキー課金設定とは別なので、連携だけのために現在の契約を切り替える必要はありません。
