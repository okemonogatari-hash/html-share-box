# ぷるもり。制作の記録

## きっかけ

うん、そうだね。カピバラバージョンのこのゼリーを作ろう。カピバラとこのインコバージョンの。

参考にしたのは[まとさんのpururu](https://pururu-slime.matodesign.workers.dev/)。触ったときの変形と弾みを観察し、コードや画像は取り込まず、カピバラとインコの形・背景・材質を独自に組みました。

## 道具

HTML / CSS / JavaScript / Three.js r147。ライセンスはvendor/THREE-LICENSE.txt。制作はCodexとnative subagent。実装担当への要求設定はAstra ultraであり、内部の実行モデルの独立した証明ではありません。外部画像・音声APIの追加利用なし。

## 公開版

2026-10-05、本人の「この作品シェアできるところに推しておいてー」の依頼で、10月4日の質感調整版をGitHub Pagesへ配置。形・動き・操作のコードはそのまま、リンク用の説明とOG画像を追加。代表画像は完成版の写真保存機能で書き出した実物です。

## 作り直すには

index.html、style.css、app.js、vendor/を同じ配置でHTTPサーバーに置きます。app.jsで形・材質・物理、style.cssで配置を調整できます。改修後は2匹の切替、つつく、ドラッグして放す、落下、色、眠る、写真保存とスマートフォン幅を確認してください。
