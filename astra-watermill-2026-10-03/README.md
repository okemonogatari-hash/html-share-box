# 水車小屋の午後

流れを変えて、木の水車・歯車・石臼を眺める、小さなブラウザ3D作品です。

## 開く

このフォルダで以下を実行し、[プレビュー](http://127.0.0.1:8873/) を開きます。

```sh
python3 -m http.server 8873 --bind 127.0.0.1
```

実行時の外部API、課金、外部モデル素材、CDN、フォント配信は使いません。Three.js r147とMITライセンスを同梱しています。WebGLが必要です。ビルドは不要です。

## 操作

- **水門のひらき**：0〜100%。流れと水門に応じて、水車が慣性を残して加減速します。0%にするとゆっくり停止します。
- **時をとめる / 時をうごかす**：水・泡・水車・歯車・石臼・光の粒のアニメーションをまとめて停止・再開。視点と屋根は停止中も操作できます。
- **小屋ぜんたい / 水車と水 / 歯車のしくみ**：見やすい位置へ滑らかに移動します。
- **屋根をひらいて、なかを見る**：手前側の屋根を外したカットモデルと、屋根を閉じた姿を切り替えます。
- **この景色を保存**：現在の視点をPNG画像として保存します。操作UIは画像に含めません。
- **はじめの景色に戻す**：流量65%、回転角0、再生中、屋根を開いた全景へ戻します。
- マウス/指でドラッグして回転、ホイール/2本指ピンチで距離を変えられます。

OSの「視差効果を減らす」に相当する `prefers-reduced-motion: reduce` が有効な場合は、静止した状態で開きます。「時をうごかす」で再生できます。

## 模型の範囲

上掛け水車、桶32個、木のリムとスポーク、軸受、40歯の木歯車、10本のランタン歯車、縦軸、石臼、穀物のホッパーを造形しています。歯車の回転比は4:1です。水量に対し水車の目標角速度を定め、時定数を持つ追従で加減速します。水の曲面・落下する粒・泡は視覚演出です。接触・水圧・実物の出力を解く工学シミュレーションではありません。

木目・石の表面はCanvasで描く手続き型テクスチャ。屋根のシングル、床板、木栓、金属の留め具、桶、麻袋、樽、小石、草、枝葉もコードで作っています。木々の葉はInstancedMeshで描画しています。静止した板・梁・石は材質ごとに結合し、可動部はグループ内で結合して描画呼出を抑えています。形状と配置には固定シードを使い、同じ見た目を再現します。

## 検査

```sh
node --check app.mjs
node qa/check-static.mjs
```

静的検査は、参照先の存在、同梱依存、DOMと操作コードの対応、ローカルファイルで完結していることを確認します。画面の見やすさや操作結果の確認は、親担当のブラウザQAとスクリーンショットを参照してください。

ブラウザでの独立検査用に `window.watermill.snapshot()` を読み取れます。流量、実回転速度、一時停止、経過時間、各回転角、屋根、視点、描画フレーム数、描画負荷の読み取り専用情報です。確認用の任意コードを作品に実行させる機能は設けていません。

## ファイル

- `index.html` / `style.css`：日本語の操作とレスポンシブUI
- `app.mjs`：独自造形・テクスチャ・アニメーション・操作
- `vendor/`：Three.js r147とライセンス
- `making.html`：公開用の短い制作解説
- `PROCESS.md` / `prompts/`：依頼・委任・素材・再制作手順
- `qa/`：静的確認。親担当の受入結果とは区別します。
