あなたのクロコで、このダッシュボードを作る

  1. 用意するもの：Mac／1Password（契約済み・Macのアプリが入っている）／Claudeのデスクトップアプリ（クロコ＝Claude Codeが使える状態）
  2. 1Passwordのアプリを開いて、ロックを解除しておく
  3. 下の「コピー」を押して、クロコに貼って送る（全部読まなくてOK）
  4. あとはクロコが1つずつ案内してくれます。1Passwordの許可が出たら、内容を見て許可。インストールなどは、クロコが説明してから聞いてくれます
あなた（Claude Code）と一緒に、私のパスワードの「健康診断ダッシュボード」を作りたいです。私は非エンジニアなので、1つずつ順番に、画面に出ている日本語の名前で案内してください。1つ終わるたびに、私の返事を待ってから次へ進んでください。

【作りたいもの】
1Passwordに入っているログイン情報を1件ずつ点検して、「全体で何点か」と「どれから直すと一番安全になるか」が見えるダッシュボード（HTMLファイル）。見た目と項目は、このサンプルを参考にしてください：https://okemonogatari-hash.github.io/html-share-box/pw-dashboard-sample/

【いちばん大事な約束】
- パスワードの値は、あなたも私も見ません。値を読んでよいのは、あなたが書く点検プログラムの中だけです。画面・ファイル・この会話に、値を出さないでください。
- 値が出る形のopコマンド（op read、op item get など）を、あなたが直接実行して結果を表示しないでください。opの出力は、点検プログラムの中だけで受け取ってください。
- 1Passwordは読み取りだけです。追加・変更・削除はしないでください。
- サイトのパスワードを変えるのは私です。あなたがサイトに入力して変更しないでください。
- 結果のファイルは、GitHubやクラウドと同期されない場所（例：ホームフォルダの中の pw-dashboard フォルダ）に、自分だけが読める権限で置いてください。
- インストールなどMac全体に影響する操作は、実行前に「何をするか」をやさしく説明して、私の許可を取ってください。
- わからないエラーが出たら、推測で別の方法を試さず、そこで止めて報告してください。

【進め方】
1. 準備の確認：Homebrew と 1Password CLI（op）が入っているか確かめてください。無ければ、入れ方を説明して許可を取ってから入れてください。
2. 1Passwordとつなぐ：1Passwordのアプリを開いてロックを解除するよう案内し、次に「1Password」メニュー →「設定…」→「開発者」→「1Password CLIと連携」にチェックを入れるよう案内してください（チェックがグレーで押せない時は、1Passwordのロックが外れているか確かめるよう伝えてください）。
3. つながったか確認：保管庫の名前と、ログイン項目の件数だけ教えてください（中身は読まない）。
4. 点検：点検プログラムを書いて実行してください。見るのは次の3つです。
 ・使い回し：別々のサイトで同じパスワードを使っている時だけ数える。同じサイトに2回保存されているだけのものは「重複」として別に数える
 ・弱いパスワード：文字の種類と長さから、ざっくり判定
 ・httpのサイト（暗号化されていないページ）
 時間がかかる時は「いま何をしていて、あと何分くらいか」を先に伝えてください。
5. 点数：「問題が1つもないログインの割合（%）」にしてください。日付と点数を記録して、何回か実行すると線グラフで変化が見えるようにしてください。
6. 画面：点数、数字のカード、危ない順の一覧（サイト名と印だけ）を出してください。お金・メール・Google／Appleなど大事なアカウントは上に。各行に「パスワード変更画面を開く」ボタンと、直したら押す「済」の印も付けてください。できたら、ブラウザで開いてください。
7. 漏えい照合は、最初は付けません。私が「漏えいも調べて」と言った時だけ、Have I Been Pwned に「値ではなく、ハッシュの先頭5文字」だけを送る方法で行ってください。送る前に、何を送るか説明して許可を取ってください。

【終わったら報告】
- 件数、点数、数字のカードの中身
- 結果ファイルに値が入っていないことを、どうやって確かめたか
- 1PasswordのWatchtowerの数字と並べて、合っているか（ずれたら理由）
- 次に私がやること（まず何から直すか、1件だけ）

守っていること：パスワードの値を読むのは、クロコが書く点検プログラムの中だけ。1Passwordは読むだけで変えない。サイトのパスワードを変えるのは、あなた自身です。（確認日 2026年10月26日・作り手 おけもん）
