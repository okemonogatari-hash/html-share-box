3貼るのは、これだけ

いつもの Claude Code に、下の文を貼って送ります。ダウンロードや解凍は、AIが自分で進めます。

そのまま貼るだけ
飛び出す絵本のムービーを作りたいです。このページを読んで、一緒に作ってください。 __KIT__start.md
  1. Claude Code を、いつも使っているフォルダで開く
  2. 上の文を貼って送る。何を作りたいかは、AIが聞いてくれます
  3. 最初の10秒の試しを見て、一言返す（「字をもっと大きく」「もっと遊んで」）

目的が決まっている方は、続けて一言足してください（例：保育園の運動会のお知らせです。10月10日（土）9時から）。凝りたい方は凝ってもOK。まずはシンプルに。

Claude Code は有料プラン（Pro・Max など）で使えます。Mac で確かめました。途中で「このコマンドを動かしていい？」と聞かれたら、読んで大丈夫そうなら許可します。

自分のキャラで作りたい時

立ち絵の画像を1つのフォルダにまとめて、作業フォルダの中に置きます。「キャラはこのフォルダの絵で」と伝えると、背景を抜いて白ふちのシールにして動かしてくれます。

人を紹介する時は、この4行を足す

自己紹介・だれかの紹介に
人の紹介なので、台本はこの4つから書いてください。
- 見る人のため息（つぶやいていそうな独り言）：【例：パン作り、むずかしそう。うちのオーブンでも焼けるのかな】
- 想い（なぜやっているのか）：【例：焼きたてを家族に出す、あのうれしさを知ってほしいから】
- その人らしい一場面：【例：失敗したパンも、笑いながら全部食べる】
- 見る人に手渡す最後の一言：【例：最初の一回は、手ぶらで来てね】
