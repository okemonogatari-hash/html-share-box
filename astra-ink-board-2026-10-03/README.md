# インクの盤上

青いボールペンで描いた立体の駒を、自分で並べて絵にするブラウザ作品。6種類の駒、白／青の描き分け、3つの構図、自由配置・移動・削除、元に戻す／やり直す、視点変更、線の調整、PNG保存ができます。

- 作品: `index.html`
- コピーできる作り方: `making.html`
- 制作記録・素材の由来・再利用プロンプト: `PROCESS.md`
- 作品URL: https://okemonogatari-hash.github.io/html-share-box/astra-ink-board-2026-10-03/

## ローカルで開く

ES modulesを使うため、ファイルを直接開く代わりにHTTPサーバーを使います。インストール作業やビルドはありません。

```sh
cd /Users/monoke/Okemori/outputs/astra-lab-2026-10-03/ink-board
python3 -m http.server 8878 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8878/` を開きます。描画にはWebGLが必要です。使えない環境では同梱の完成見本と案内が出ます。

## 遊び方

1. 最初は8駒の「余白のある午後」です。盤の駒を選び、空いたマスをタップすると移動します。別の駒をタップすると選択が変わります。
2. 駒の種類か白／青を選ぶと「駒を置く」へ切り替わります。空きマスに何個でも置けます。駒のあるマスへの追加は短い説明とともに止めます。
3. 駒を選んで「選んだ駒を消す」で削除。配置・移動・削除・構図切り替えは「元に戻す／やり直す」に対応します。新しい編集をするとやり直しの分岐は解消します。
4. 「斜めから／真上から」と左右ボタンで眺める向きを変え、インクの濃さと線の重なりを調整します。
5. 「一枚の絵として保存」で盤だけをPNGにします。選択枠やキーボードのマス印は入りません。

マス指定メニューでも同じ操作ができます。Canvasにフォーカスし、矢印でマスを選び、Enter／Spaceで操作、Escapeで選択解除、Delete／Backspaceで選択中の駒を消します。矢印は盤のa〜h／1〜8に沿います。⌘／Ctrl＋Z、Shift付きのやり直しにも対応。チェスの移動ルール・勝敗・CPU対局は実装していません。

構図の初期値は8駒／6駒／32駒です。「まっさらな盤」で空にできます。ページを再読込すると初期状態へ戻ります。操作中の並びは端末内のメモリにあり、ネットワークへ送信しません。

## 実装の場所

| ファイル | 内容 |
|---|---|
| `model.mjs` | 盤の状態、配置、移動、削除、履歴、3構図、入力の検証、カメラ、保存状態のコピー |
| `geometry.mjs` | 台座・輪郭・冠・十字・城壁・馬の横顔、盤の線、接地線、余白の小さな印 |
| `renderer.mjs` | WebGLの深度テスト、紙とインクのシェーダー、線幅、手前にある駒の選択判定 |
| `app.mjs` | タップとキーボード、画面との接続、操作時だけの描画、PNGの同期コピーとURL解放 |
| `style.css` | クリーム色の冊子風レイアウト、375px表示、フォーカスと選択時の配色 |
| `qa/model.test.mjs` | 状態・履歴・保存の独立性・実頂点の画面内フィットなど11件の検査 |

外部CDN、外部フォント、外部画像、追加ライブラリはありません。紙の粒子も駒も計算描画です。`poster.png`は親担当が実ブラウザの保存画像から作成したものです。

## 再制作するとき

`making.html`のプロンプトをコピーして使えます。形や線を変更したら、上のテストに加え、少なくとも全32駒／真上／左右一周／スマホで画面内に収まるか、空きマスと駒の選択が正しいか、保存PNGに選択印が入らないかを実ブラウザで確認してください。最終PNGを保存し、`poster.png`を更新してから公開先を再読込します。
