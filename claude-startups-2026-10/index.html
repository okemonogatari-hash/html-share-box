01

何がもらえるの？

もらえる物中身注意
Claude Team 1年無料会社向けプラン。Premium 席（通常席の5倍使える）が最大5席Team を初めて使う組織だけ。今の個人プラン（Pro / Max）がそのまま無料になる制度ではなく、別の組織として作る
API クレジット1,000ドル分付与から6か月（180日）で失効
提携ツールの優待営業・デザイン・データ系のツールで最大45,000ドル相当中身は承認後に見える
相談会Anthropic の Applied AI チームとのオフィスアワー（隔週45分）承認後に案内が届く

Premium 席の定価は年払いで月100ドル。5席×12か月で約6,000ドル。公式の X は「最大7,000ドル分の Claude 製品とクレジット」と表現しています。

02

誰が応募できるの？

公式の条件は、次のどちらか一方。

  • 設立から 5年以内
  • または、直近 2年以内に資金調達をしている

公式 FAQ に「VC の資金は不要。ブートストラップ（自己資金）、プレシード、VC 支援のどれも対象」と書いてあります。資金調達していない人は、設立年数の方で入ります。

はっきり書いていないこと法人登記が必要か、個人事業主でもよいかは、公式ページにも FAQ にも書かれていません。対象の表現は「startups founded in the last five years」で、法人格ではなく「いつ始めたか」で切っています。実例では、登記していない一人の開発者が通った報告が複数あります（次の章）。

申請に要る物は3つ。（公式ページの原文を日本語に）

  1. Claude Console のアカウント（Anthropic の開発者向け管理画面）
  2. 自分のサイトのドメインと一致する会社メール（例：サイトが example.com なら、info@example.com）
  3. 何を作っているかの短い説明

通った人と落ちた人の、分かれ目

10月7日に制度が広がってから24時間分、X の報告を集めました。承認も却下も「申請から数分」で来ているので、人が読んでいるというより、自動の照合に見えます。

通った人（自己申告）落ちた人（自己申告）
登記した会社なし・資金なし・売上0。3分で承認（インドの一人開発者）法人（LLC）で、会社メールもサイトもあるのに2分で却下
自己資本で4期目、すぐ通った（日本）Gmail などの個人メールで申請して通らず、「自分のドメインのメールでやり直す」
資金調達なしの2人の会社、3分後に承認メール（日本）無料のドメインで申請して却下
医療現場向けの AI・DX 支援を「作っている物」として申請し採択（日本）AI に代わりに申請させて、アカウントがブロックされ異議申し立て中

却下の文面はほぼ一つ。「couldn't verify the company（会社を確認できませんでした）」。法人でも、売上があっても出ています。通った人の自己申告を集めると、見られているのは次の3点に絞れます。

  1. 申請に使ったメールのドメインが、自分のサイトのドメインと同じか
  2. そのサイトに、動いている物（サービス・製品・実績）が載っているか
  3. 「何を作っているか」の説明が、サイトの内容と一致しているか

通った人が書いていた助言も添えます。Console は「個人」ではなく「組織」として作る。Claude を道具として使っているだけの代理店・制作会社型は落ちやすい印象で、「Claude で作っている物」を前に出す。新しく取ったドメインにテンプレートのサイトだと確認されにくい印象。どれも本人が「公式見解ではない」と断っています。

04

みずやんの自己チェック

上から順に。全部☑なら、申請は数分で終わります。

  • 始めてから5年以内？（開業届の日付、または会社の設立日）
  • 自分のドメインのサイトがある？（◯◯.com など。無料のサブドメインや note・ブログサービスだけだと、確認されにくい）
  • そのドメインで受け取れるメールがある？（info@◯◯.com など。無ければ、ドメインの管理画面で転送設定すれば無料で作れることが多い）
  • サイトに「何をしている人か」と「動いている物」が載っている？（サービス、制作実績、使えるツール、など）
  • 「Claude で何を作っているか」が一言で言える？（「AI を使って支援しています」より「◯◯を Claude で作って、△△の人が使っている」の形）
  • Claude Team をまだ契約していない？（契約済みだと Team の無料特典は対象外）
ドメインが無い場合うちも同じ状況でした。サイトが GitHub の無料ドメインで、メールが Gmail。独自ドメインは年1,000〜2,000円で取れて、受信メールの転送と、今のサイトへの割り当ては無料でできます。申請のためだけでなく、名刺や請求書に自分の住所が載るので、取る価値はあると判断して準備中です。

05

申請の手順（5ステップ）

  1. ドメインのメールを用意する。サイトと同じドメインで、受信できるアドレスを1つ。
  2. Claude Console のアカウントを、そのメールで作る。種別は「組織（organization）」。platform.claude.com
  3. 申請フォームを開く。platform.claude.com/offers/startups-application（サインイン後に中身が見えます）。
  4. 「何を作っているか」を具体的に書く。何をする物か、誰が使うか、Claude がどこに入っているか。サイトに書いてあることと揃える。
  5. 自分の手で送信する。多くは数分で結果メール。手動審査に回ると2〜3営業日。

06

申請前に知っておくこと

AI に代わりに申請させないブラウザ操作 AI やエージェントに申請を任せて、アカウントがブロックされた報告があります。フォームは自分の手で。
規約を読む承認後に会社名やロゴが Anthropic の紹介に使われる許諾が入っていると、申請者が指摘しています。送信前に Additional Benefits の規約を一度読んでください。
  • API クレジットは付与から6か月で消えます。使う予定が無くても、もらって損はありませんが、期限は覚えておく。
  • Team は今の個人プランとは別の組織です。移行ではなく「もう1つ席ができる」イメージ。
  • 承認後、Team の受け取り画面がどこにあるか迷った人がいます。承認メールの案内と、Console の「Claude Startups」ページを見る。
  • 却下されても理由は「確認できなかった」としか来ません。メール・サイト・説明文の3点を揃えて再申請した人もいますが、何回まで出せるかは公式に書いていません。1回目を一番よい状態で出すのが安全です。
