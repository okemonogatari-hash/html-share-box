        有料プランは3つとも月額制で、使える量に上限があります。上限のあとも続けたい時は、自分で追加分を買う形です。金額は公式のドル表示のまま載せています。

        Claude Code

        20ドル／月から

        Proプランの金額です。無料プランにClaude Codeは入っていません。上にMax（100ドル）とUltra（200ドル）があります。

        Codex

        0ドルから

        無料プランとGo（8ドル）はパソコンのアプリだけで、順番に提供されている途中です。Plus（20ドル）ならブラウザやiPhoneからも使えます。上にPro（100ドルから）があります。

        正直メモ

        • 公式ページの金額はドル表示です。日本円での請求額は、為替と税、申し込む場所で変わります。

        04

        はじめの3歩

        上でえらんだAIの手順が開いています。ほかの2つも、名前を押すと見られます。

        1. ClaudeをProにするClaudeに登録して、月20ドルのPro以上をえらびます。
        2. アプリで「コード」を開くパソコンにClaudeのアプリを入れて、「コード」をえらびます。黒い画面は使いません。
        3. フォルダを1つ渡す今日の作業場にするフォルダをえらんで、「このフォルダは何？」と聞いてみます。

        フォルダは、新しく作った空のもので大丈夫です。大事なファイルが入った場所から始める必要はありません。

        1. Codexを開くChatGPTのアカウントでサインインします。
        2. フォルダをえらぶ作業してほしい場所を1つえらびます。
        3. 小さく1つ頼む「このフォルダの中身を一覧にして」くらいの大きさから始めます。

        ChatGPTで話した内容は、Codexにはそのまま伝わりません。必要なことは、頼む時にもう一度書きます。

        1. Museを開くスマホのアプリか、パソコンで muse.ai を開きます。
        2. 登録する携帯番号かメールアドレスで登録します。
        3. チャットで頼む送信などの前には、承認を求めてきます。中身を読んでからOKを押します。

        無料の枠には上限があります。おけもんは最初の4日でほぼ使い切りました。最初は用事を1つに絞るのがおすすめです。

        05

        ちょっと不安なこと

        オフ会やAIシェア会でよく出る質問と、先に知っておいてほしいことです。

        「許可しますか？」と何度も聞かれて、怖いです。

        あれは、AIが勝手に進めないための確認です。ファイルを消す、外へ送るといった操作の前には確認が出ます。読んで分からなければ、「これは何をする許可？」とそのまま聞き返せます。確認を全部とばす設定は、慣れるまで使わないでください。

        黒い画面や英語は出てきませんか。

        3つとも、ふつうのアプリの画面から始められます。英語で返ってきたら「日本語で教えて」と書けば切り替わります。

        知らないうちに請求が増えませんか。

        月額制で、使える量に上限があります。上限に届いたら「しばらく待つ」「上のプランにする」「追加分を買う」から自分でえらびます。Claude CodeとCodexの追加分は、自分で設定や購入をした時に使う仕組みです。従量制のサービスを別につないだ時は、そちらの請求にも気をつけてください。

        3つとも契約したほうがいいですか。

        1つで足ります。任せる作業が増えて、1つでは合わない用事が出てきたら、その時に2つ目を足せば間に合います。

        ChatGPTと、何がちがうんですか。

        見分ける所は、どの会社のものか、話す窓口か作業の係か、どの情報と道具を使えるか、の3つです。いまはChatGPTでもファイルを作れるので、境目はだんだん薄くなっています。

        入れてはいけない情報はありますか。

        パスワードと、お客さんの名簿や連絡先は入れないでください。仕事の資料を渡す時は、外に出してよい内容かを先に自分で確かめます。

        おけもんはこう使ってます

        スマホではChatGPT、パソコンではCodexとClaude Codeが中心です。任せていることと、しくじった話をそのまま載せます。

        Claude Code

        毎日の記録、資料、動画、ホームページ。形に残るものは、ここで作っています。

        2026年の3月から使っています。旅の思い出ムービーを2本作って見比べたのもここです。

        Codex

        毎週の「水曜AIラジオ」の告知と、朝の情報集め。

        告知は、投稿したあとに自分で開き直して、文と画像とリンクを確かめるところまで任せています。

        Muse

        コミュニティでの返信の下書きと、歩数や食事の記録。

        返信は、文面を読んで直してからOKを押しています。食事の写真は14日つづけて記録できました。

        しくじりメモ

        • Muse無料の枠を、最初の4日でほぼ使い切りました。
        • Muse任せた返信が、返信の形にならないまま投稿されました。いまは文面を読んで直してからOKを押しています。
        • Codexパソコンの整理を頼んだら、何度やり直しても途中で止まりました。
        • Claude Code有料の音声サービスを、断られた理由を見ないまま何度も呼び直して、1日100回の上限に届きました。
